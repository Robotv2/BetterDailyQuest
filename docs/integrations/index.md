# Integrations and presentation

BetterDailyQuest runs without optional integrations. Add them only for a specific administrator outcome.

| Need | Integration |
| --- | --- |
| Show the next quest group refresh in another plugin | [PlaceholderAPI](placeholderapi.md) |
| Build a menu, scoreboard, or richer player quest browser | [Presentation plugin or addon](presentation.md) |
| Give different assignment limits to permission roles | [Vault](vault.md) plus a permissions provider |
| Add BetterDailyQuest-specific behavior supplied as a JAR | [Addon](addons.md) |

Always verify the integration on the same server version and BetterDailyQuest release used in production.
