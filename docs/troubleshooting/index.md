# Troubleshooting

Start from the symptom, change one thing at a time, and keep the complete console context around the first BetterDailyQuest error.

<div class="grid cards" markdown>

-   **Plugin does not enable**

    [Check startup](startup.md)

-   **Quest group or quest is skipped**

    [Check content loading](content-loading.md)

-   **Player does not receive a quest**

    [Check assignments](assignments.md)

-   **Activity does not count**

    [Check progress](progress.md)

-   **Reward does not run**

    [Check reward actions](rewards.md)

-   **Refresh or reroll is surprising**

    [Check replacement behavior](refresh-reroll.md)

-   **Database or integration fails**

    [Check storage and integrations](storage-integrations.md)

-   **Still blocked**

    [Prepare a support report](support-report.md)

</div>

Do not delete the database, `.libs` directory, or live quest files as a first diagnostic step. Make a backup before any recovery action.
