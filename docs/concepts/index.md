# Core concepts

BetterDailyQuest separates configured content from each player's progress. Understanding that boundary makes assignment, refresh, reroll, and completion behavior predictable.

## Read in this order

1. [Quest groups, quests, and tasks](content-model.md)
2. [Assignment lifecycle](assignment-lifecycle.md)
3. [Refresh, restart, and reroll](replacement-actions.md)
4. [Assignment limits and completion history](assignment-limits.md)
5. [Options and inheritance](options-inheritance.md)

The guide uses **quest group** in prose and the exact `group` name in commands and configuration. A command named `reset` is described as an **assignment restart** when that is its actual effect.
